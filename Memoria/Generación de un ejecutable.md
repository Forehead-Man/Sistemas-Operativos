- **Compilación:** generación del código de máquina correspondiente a cada módulo fuente.

- **Enlace o montaje (link):** se genera el ejecutable agrupando todos los módulos objeto y resolviendo las referencias entre módulos. Este enlazado puede ser estático o dinámico. En este último caso, el módulo no es incluido sino que se enlaza al momento de ejecutar el programa en forma dinámica.
