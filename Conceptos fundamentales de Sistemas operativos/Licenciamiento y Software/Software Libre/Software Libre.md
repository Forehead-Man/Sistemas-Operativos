**Definición:** Software que respeta las 4 libertades esenciales del usuario definidas por la FSF (Free Software Foundation):

1. Libertad 0: Usar el programa con cualquier propósito.
2. Libertad 1: Estudiar y modificar el código fuente.
3. Libertad 2: Distribuir copias.
4. Libertad 3: Mejorar el programa y publicar las mejoras.
